# Данил Музафаров — AI Automation Portfolio

Первая часть тестового задания Goulash.tech: сайт-портфолио с акцентом на автоматизацию бизнес-процессов.

## Запуск
Статический сайт без зависимостей и сборки.
Из корня проекта: `python -m http.server 4173 --directory dist`.
Открыть http://localhost:4173.

## Структура
- dist/index.html — содержание, семантическая разметка, раскрывающиеся описания кейсов.
- dist/style.css — адаптивная вёрстка.
- .openai/hosting.json — настройки Sites.

## Содержание и точность
Источник опыта и показателей — предоставленное кандидатом резюме.
Названия компаний разрешены кандидатом к использованию.
Направления применения опыта в Goulash.tech и процесс пилота обозначены как предложения.
Не добавлены неподтверждённые навыки SQL, обучение сотрудников или проекты ERP/CRM.
13–21 ч — разница между 16–24 и 3 часами. 12× — отношение 6 часов к 30 минутам.
STT: сохранён размер выборки (14 аудиозаписей, 346 секунд).
Исходные PDF не включены в публичные файлы сайта.

## Реализация
HTML + CSS; без JS, внешних шрифтов, трекеров и API-ключей.
Нативные details/summary для раскрытия кейсов; якорная навигация; ссылки на контакты.
Адаптация для мобильных экранов, клавиатурный фокус, skip-link, prefers-reduced-motion.
Разместить можно на любом статическом хостинге.

## Проверка
Проверены локальная HTTP-доступность, локальные ссылки/якоря и наличие входной страницы.
Браузерное визуальное тестирование не выполнялось.

## Сдача задания
Потребуются общедоступная ссылка сайта и ссылка на репозиторий, доступные проверяющему.
Приватный предпросмотр Sites сам по себе не заменяет публичную ссылку для HR.
