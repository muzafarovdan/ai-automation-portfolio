# Данил Музафаров — AI Automation Portfolio

Сайт-портфолио для первой части тестового задания Goulash.tech. Показывает опыт автоматизации бизнес-процессов: RAG-консультант, генерация контента, OCR в ритейле, автоматизация релизов и оценка речевых моделей.

## Локальный запуск

Сайт написан на HTML и CSS. Установка зависимостей и сборка не нужны.

Можно открыть `dist/index.html` прямо в браузере. Для работы через локальный сервер понадобится Python 3. Из корня проекта выполните:

```bash
python -m http.server 4173 --bind 127.0.0.1 --directory dist
```

В Linux / WSL команда может называться `python3`:

```bash
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

Откройте [http://127.0.0.1:4173](http://127.0.0.1:4173). Остановить сервер можно сочетанием `Ctrl+C`.

## Структура проекта

- `dist/index.html` — содержание страницы, проекты, опыт и контакты.
- `dist/style.css` — оформление и адаптация под мобильные экраны.
- `dist/.nojekyll` — служебный файл для статического хостинга; на локальный запуск не влияет.
- `.gitignore` — исключения для Git.

## Редактирование

Изменяйте тексты и ссылки в `dist/index.html`, стили — в `dist/style.css`. После сохранения обновите страницу в браузере.

## Реализация

- HTML и CSS, без JavaScript, внешних шрифтов и трекеров.
- Нативные `details` / `summary` для раскрытия описаний проектов.
- Якорная навигация и ссылки на контакты.
- Адаптивная вёрстка, клавиатурный фокус и ссылка перехода к содержимому.
- Поддержка `prefers-reduced-motion`.

## Данные проектов

Опыт и показатели взяты из резюме. Направления применения опыта в Goulash.tech и подход к новым пилотам обозначены как предложения.

- 13–21 час — разница между 16–24 и 3 часами работы над материалом.
- 12× — отношение 6 часов к 30 минутам в процессе релиза.
- STT-метрики относятся к выборке из 14 аудиозаписей общей длительностью 346 секунд.

## Проверка

Проверены локальная HTTP-доступность, внутренние ссылки и наличие файлов сайта. Полное браузерное тестирование не выполнялось.
